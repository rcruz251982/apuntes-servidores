🌐 1. Redes y Diagnóstico (Windows & Linux)

🖥️ Comprobación de IP en Windows (CMD)

Comando fundamental para conocer la dirección IP privada de tu ordenador y la puerta de enlace (router)[cite: 5].

ipconfig

Muestra la configuración de red actual del equipo Windows[cite: 5].

🔍 Consulta de Dominios (Ping)

Verifica la conectividad y traduce un nombre de dominio de texto a su dirección IP numérica correspondiente[cite: 5].

ping google.com

Devuelve la IP (ej: 64.233.167.101) y mide la latencia de respuesta[cite: 5].

🐧 Identificación de Red en el Servidor

Comando ejecutado dentro de Ubuntu Server para conocer la dirección IP que le ha asignado dinámicamente el router[cite: 5].

ip addr

Muestra las interfaces de red y la IP privada del servidor virtual[cite: 5].

🧭 2. Navegación y Estructura de Directorios

📂 Movimiento entre Directorios

Ejemplos de desplazamiento utilizando rutas absolutas, relativas y atajos del sistema[cite: 5].

cd /

Ir directamente a la raíz del sistema[cite: 5].

cd ~

Ir a la carpeta personal del usuario activo[cite: 5].

cd ../..

Subir dos niveles hacia arriba en el árbol de carpetas de golpe[cite: 5].

📍 Ubicación y Esquemas

Comprobar dónde estás situado y visualizar gráficamente la jerarquía de archivos y carpetas[cite: 5].

pwd

Muestra la ruta absoluta exacta de dónde estás situado (ej: /home/usuario)[cite: 5].

tree

Genera un esquema visual en árbol de todo el contenido actual[cite: 5].

📁 3. Creación de Estructuras y Archivos de Configuración

🏗️ Estructuras Anidadas (mkdir)

Creación simultánea de múltiples carpetas o árboles completos de directorios de golpe con la opción -p[cite: 5].

mkdir origen destino

Crea ambas carpetas principales en paralelo[cite: 5].

mkdir -p origen/config origen/app

Crea subcarpetas internas de una sola vez[cite: 5].

mkdir -p facturas/2026/septiembre

Crea una ruta compleja anidada completa[cite: 5].

📝 Escritura Rápida sin Editor (cat + EOF)

Crear archivos de texto o configuración directamente introduciendo líneas de contenido desde la terminal[cite: 5].

cat <<EOF > origen/config/pantalla.conf
resolucion: 1980x1024;
color: 32bits;
tactil: true
EOF

Escribe texto línea a línea y lo guarda en el archivo (sobrescribiendo si ya existía)[cite: 5].

🔎 Búsqueda Avanzada (Find y Grep)

Localizar archivos específicos en subcarpetas o buscar texto concreto dentro de los ficheros[cite: 5].

find -name audio.conf

Busca ficheros por nombre de manera recursiva en todo el árbol[cite: 5].

grep -R 'archivo'

Busca una palabra o texto determinado dentro de los archivos de forma recursiva[cite: 5].

🔄 4. Copia, Movimiento y Operaciones Complejas

📋 Ejemplos de Copia (cp)

Uso de opciones avanzadas para duplicar archivos y carpetas enteras con seguimiento visual[cite: 5].

cp -v origen/config/pantalla.conf destino

Copia un archivo mostrando el progreso detallado en pantalla[cite: 5].

cp -rv origen/app destino

Copia una carpeta entera de forma recursiva con modo detallado (verbose)[cite: 5].

cp -vr destino/configuracion/. origen/config

Copia únicamente el contenido interno de un directorio usando /. sin arrastrar la carpeta contenedora[cite: 5].

🚚 Ejemplos de Movimiento y Renombrado (mv)

Reubicar elementos, renombrarlos o aplicar operaciones múltiples mediante llaves {}[cite: 5].

mv -v origen/config/audio.conf destino

Mueve el archivo de configuración a la nueva ruta designada[cite: 5].

mv -v {destino/audio.conf,destino/pantalla.conf} destino/configuracion

Mueve varios archivos agrupados entre llaves de manera simultánea[cite: 5].

cp -v remot.app remot.bak

Crea una copia de seguridad rápida cambiando la extensión a formato .bak[cite: 5].

🗑️ Ejemplos de Borrado y Limpieza (rm)

Eliminación segura de ficheros sueltos o purgado de directorios con diferentes niveles de precaución[cite: 5].

rm -i archivo.txt

Borra pidiendo confirmación interactiva previa (sí/no)[cite: 5].

rmdir albaranes

Borra exclusivamente carpetas que se encuentren totalmente vacías[cite: 5].

rm -rf carpeta

Fuerza la eliminación recursiva de una carpeta con todo su contenido sin previo aviso (¡Peligro!)[cite: 5].

💡 Consejo práctico: Recuerda que puedes utilizar la tecla **Tabulador** en la terminal para autocompletar nombres de archivos y carpetas largos automáticamente, evitando errores de escritura[cite: 5].
