📚 Manual Definitivo: Servidores, Redes y Linux

Apuntes visuales y prácticos para el curso.

🌐 1. Conceptos de Redes e IPs

🌍 Direcciones IP y Redes

Formato: NNN.NNN.NNN.NNN (cada número de 0 a 255). Ej: 192.168.1.35 es válida; 192.340.1.35 es incorrecta.

  • WAN: Red amplia geográficamente.
  • LAN: Red local (edificio, casa), comúnmente 192.168.1.X.

🔍 Cómo averiguar tus IPs

IP Pública: Buscando en internet.

ipconfig → En la terminal de Windows (CMD) para ver tu IP privada y puerta de enlace (router).

📂 Servidores DNS y Tipos de Servidores

DNS: Convierten dominios de texto en IPs numéricas (puedes consultarlo haciendo ping dominio.com).

Servicios comunes: Web (Apache), SSH (acceso remoto), FTP/SFTP (transferencia de ficheros), MySQL (BD), Samba (compartir carpetas), Correo (IMAP/SMTP).

💻 2. Configuración de Máquinas Virtuales (VirtualBox)

⚙️ Requisitos de Creación

  • Instalación previa: Descargar Microsoft Visual C++ 2019 y VirtualBox.
  • Hardware base: Mínimo 2 GB de RAM y 1 procesador.
  • ¡Importante!: Marcar Omitir instalación desatendida.
  • Disco Duro: 25 GB de tipo dinámico (crece según se use, formato VDI).

🖧 Adaptador Puente (Crucial)

Antes de arrancar la máquina virtual, debes ir a Configuración > Red y cambiar el conexionado a Adaptador Puente.

¿Por qué? Para que tu servidor Ubuntu forme parte directa de tu red local y tenga su propia IP dentro de ella.

🐧 Instalación de Ubuntu Server

  • Seleccionar idioma español y distribución de teclado.
  • Desactivar el grupo LVM en el disco duro.
  • Omitir la actualización de Ubuntu Pro (es de pago).
  • ¡Vital!: Marcar la casilla de Instalar servidor OpenSSH para poder controlarlo cómodamente desde Windows.

🔌 3. Conexión y Control del Servidor

🖥️ Comandos dentro de Ubuntu

ip addr → Muestra la IP actual asignada al servidor. sudo shutdown now → Apaga el servidor de forma segura (pide contraseña).

🪟 Conexión SSH desde Windows

Abre el CMD de Windows y conéctate de forma remota escribiendo:

ssh usuario@ip_servidor → Te pedirá la contraseña del servidor y entrarás directamente a la terminal Linux.

📂 4. Estructura de Directorios y Rutas en Linux

🗂️ El Árbol de Directorios (La Raíz /)

  • /etc: Archivos de configuración del sistema.
  • /home: Ubicación de los usuarios (la tilde ~ representa tu usuario).
  • /opt: Software de terceros.
  • /usr: Programas propios del servidor.
  • /srv: Datos de servicios (web, ftp).
  • /var: Datos variables (logs, webs).

🧭 Tipos de Rutas

  • Absolutas: Empiezan siempre desde la raíz / (ej: cd /home/usuario/facturas).
  • Relativas: Se mueven desde donde estás ubicado (ej: cd facturas).
  • Subir niveles: Usando cd .. o encadenados como cd ../...
pwd → Muestra la ruta exacta de dónde estás situado.

💻 5. Comandos de Archivos, Carpetas y Comodines

👁️ Listar Archivos (ls)

ls Listado normal ls -l Listado detallado ls -a Muestra archivos ocultos (con punto) ls -t Ordena por fecha (recientes primero)

Comodines de búsqueda (*): A* (empieza por A), *A (acaba por A), *A* (contiene A).

📝 Crear Archivos y Carpetas

touch archivo.txt Crea archivo en blanco mkdir carpeta Crea una carpeta mkdir -p a/b/c Crea estructura anidada de golpe nano archivo.txt Editor de texto (CTRL+S guardar, CTRL+X salir)

🗑️ Borrado de Archivos y Carpetas

rm archivo.txt Borra un archivo rm -i archivo.txt Borra pidiendo confirmación rmdir carpeta Borra carpeta vacía rm -rf carpeta Borra carpeta con todo sin previo aviso (¡Peligro!)
💡 Truco extra de árbol: Si quieres ver de forma gráfica toda la estructura de carpetas tipo esquema, puedes instalar la herramienta ejecutando sudo apt install tree y luego escribir tree.
