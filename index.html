🌐 1. Conceptos de Redes e IPs

🌍 Direcciones IP y Redes

Formato: NNN.NNN.NNN.NNN (cada número de 0 a 255). Ej: 192.168.1.35 es válida; 192.340.1.35 es incorrecta.

  • WAN: Red amplia geográficamente.
  • LAN: Red local (edificio, casa), comúnmente 192.168.1.X o 10.0.1.X.
  • Router / Puerta de enlace: Dispositivo que interconecta la LAN con la WAN (ej: 10.0.0.1).

🔍 Cómo averiguar tus IPs

IP Pública: Buscando en internet (ej: 83.48.1.214).

ipconfig → En la terminal de Windows (CMD) para ver tu IP privada y puerta de enlace (router).

📂 Servidores DNS y Tipos de Servidores

DNS: Convierten dominios de texto en IPs numéricas. Puedes consultarlo haciendo ping dominio.com para que devuelva su IP (ej: 64.233.167.101).

Servicios comunes: Web (Apache), SSH (acceso remoto), FTP/SFTP (transferencia de ficheros), MySQL (BD), Samba (compartir carpetas), Correo (IMAP/SMTP).

💻 2. Configuración de Máquinas Virtuales (VirtualBox)

⚙️ Requisitos de Creación

  • Instalación previa: Descargar Microsoft Visual C++ 2019 y VirtualBox.
  • Hardware base: Mínimo 2 GB de RAM y 1 procesador.
  • ¡Importante!: Marcar Omitir instalación desatendida.
  • Disco Duro: 25 GB de tipo dinámico (crece según se use, formato VDI).

🖧 Adaptador Puente (Crucial)

Antes de arrancar la máquina virtual, debes ir a Configuración > Red y cambiar el conexionado a Adaptador Puente.

¿Por qué? Para que tu servidor Ubuntu forme parte directa de tu red local y tenga su propia IP dentro de ella.

🐧 Instalación de Ubuntu Server

  • Seleccionar idioma español y distribución de teclado.
  • Desactivar el grupo LVM en el disco duro.
  • Omitir la actualización de Ubuntu Pro (es de pago).
  • ¡Vital!: Marcar la casilla de Instalar servidor OpenSSH para poder controlarlo cómodamente desde Windows.

🔌 3. Conexión y Control del Servidor

🖥️ Comandos dentro de Ubuntu

ip addr → Muestra la IP actual asignada al servidor. sudo shutdown now → Apaga el servidor de forma segura (pide contraseña).

🪟 Conexión SSH desde Windows

Abre el CMD de Windows (símbolo del sistema) y conéctate de forma remota escribiendo:

ssh usuario@ip_servidor → Te pedirá la contraseña del servidor y entrarás directamente a la terminal Linux.

📂 4. Estructura de Directorios y Rutas en Linux

🗂️ El Árbol de Directorios (La Raíz /)

  • /etc: Archivos de configuración del sistema.
  • /home: Ubicación de los usuarios (la tilde ~ representa tu usuario).
  • /opt: Software de terceros.
  • /usr: Programas propios del servidor.
  • /srv: Datos de servicios (web, ftp).
  • /var: Datos variables (logs, webs).

🧭 Tipos de Rutas

  • Absolutas: Empiezan siempre desde la raíz / (ej: cd /home/usuario/facturas o cd /etc).
  • Relativas: Se mueven desde donde estás ubicado (ej: cd facturas o cd ../../etc).
  • Subir niveles: Usando cd .. o encadenados como cd ../...
pwd → Muestra la ruta exacta de dónde estás situado.

💻 5. Comandos de Archivos, Carpetas y Operaciones Avanzadas

👁️ Listar Archivos (ls) y Búsquedas

ls Listado normal ls -l Listado detallado ls -a Muestra archivos ocultos (con punto) ls -t Ordena por fecha (recientes primero) ls -R Listado recursivo (incluyendo subcarpetas)

Comodines (*): A* (empieza por A), *A (acaba por A), *A* (contiene A).

find -name audio.conf Busca ficheros en subcarpetas. grep -R 'texto' Busca texto dentro de archivos recursivamente.

📝 Crear Archivos y Contenido

touch archivo.txt Crea archivo en blanco nano archivo.txt Editor de texto (CTRL+S guardar, CTRL+X salir, CTRL+F buscar) cat archivo.txt Visualiza contenido rápidamente

Crear o reescribir con cat y EOF:

cat <<EOF > archivo.txt Texto de cero (sobrescribe si existe). Línea a línea. EOF

Redirecciones:

> Machaca/sobrescribe el contenido del archivo. >> Añade contenido al final del archivo sin borrar lo anterior.

📁 Crear Carpetas

mkdir carpeta Crea una carpeta mkdir c1 c2 Crea varias carpetas a la vez mkdir -p a/b/c Crea estructura anidada de golpe

Herramienta Tree:

tree Muestra esquema gráfico de carpetas. Si no está: sudo apt install tree

📋 Copiar Archivos y Carpetas (cp)

cp origen.txt destino.txt Copia y renombra cp origen.txt /etc Copia a otra ruta cp -i Pregunta antes de sobrescribir cp -u Copia sólo si es más reciente cp -v Muestra progreso cp -r Copia recursiva (carpetas enteras) cp -a Copia total conservando permisos, fechas y propietario

Truco copia de contenido limpio: cp -r origen/. destino copia solo el contenido interno sin arrastrar la carpeta contenedora.

🚚 Mover y Renombrar (mv)

mv origen.txt backup.bak Renombra un archivo mv -i Pregunta antes de sobrescribir mv -v Muestra el proceso ejecutado mv -uv a* backup/ Mueve recursivamente solo los ficheros actuales que empiezan por a

Truco múltiples archivos con llaves:

mv -v {d1/a.conf,d1/b.conf} d2/config/

🗑️ Borrado de Archivos y Carpetas (rm)

rm archivo.txt Borra un archivo rm -i archivo.txt Borra pidiendo confirmación rmdir carpeta Borra carpeta vacía rm -r carpeta Borra carpeta con todo (sin aviso previo, ¡Cuidado!) rm -rf carpeta Fuerza eliminación sin preguntar (sólo atrevidos) rm -rfi carpeta Fuerza la eliminación preguntando paso a paso
💡 Nota técnica previa: Recuerda que SUDO significa Super User Do / Substitute User Do y APT proviene de Advanced Package Tool. ¡Todo listo y condensado a mano para tus prácticas!
