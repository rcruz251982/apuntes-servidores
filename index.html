🌐 1. Conceptos de Redes e IPs

🌍 Direcciones IP y Redes

Formato: NNN.NNN.NNN.NNN (cada número de 0 a 255). Ej: 192.168.1.35 es válida; 192.340.1.35 es incorrecta[cite: 2].

  • WAN: Red amplia geográficamente[cite: 2].
  • LAN: Red local (edificio, casa), comúnmente 192.168.1.X[cite: 2].

🔍 Cómo averiguar tus IPs

IP Pública: Buscando en internet[cite: 2].

ipconfig → En la terminal de Windows (CMD) para ver tu IP privada y puerta de enlace (router)[cite: 2].

📂 Servidores DNS y Tipos de Servidores

DNS: Convierten dominios de texto en IPs numéricas (puedes consultarlo haciendo ping dominio.com)[cite: 2].

Servicios comunes: Web (Apache), SSH (acceso remoto), FTP/SFTP (transferencia de ficheros), MySQL (BD), Samba (compartir carpetas), Correo (IMAP/SMTP)[cite: 2].

💻 2. Configuración de Máquinas Virtuales (VirtualBox)

⚙️ Requisitos de Creación

  • Instalación previa: Descargar Microsoft Visual C++ 2019 y VirtualBox[cite: 2].
  • Hardware base: Mínimo 2 GB de RAM y 1 procesador[cite: 2].
  • ¡Importante!: Marcar Omitir instalación desatendida[cite: 2].
  • Disco Duro: 25 GB de tipo dinámico (crece según se use, formato VDI)[cite: 2].

🖧 Adaptador Puente (Crucial)

Antes de arrancar la máquina virtual, debes ir a Configuración > Red y cambiar el conexionado a Adaptador Puente[cite: 2].

¿Por qué? Para que tu servidor Ubuntu forme parte directa de tu red local y tenga su propia IP dentro de ella[cite: 2].

🐧 Instalación de Ubuntu Server

  • Seleccionar idioma español y distribución de teclado[cite: 2].
  • Desactivar el grupo LVM en el disco duro[cite: 2].
  • Omitir la actualización de Ubuntu Pro (es de pago)[cite: 2].
  • ¡Vital!: Marcar la casilla de Instalar servidor OpenSSH para poder controlarlo cómodamente desde Windows[cite: 2].

🔌 3. Conexión y Control del Servidor

🖥️ Comandos dentro de Ubuntu

ip addr → Muestra la IP actual asignada al servidor[cite: 2]. sudo shutdown now → Apaga el servidor de forma segura (pide contraseña)[cite: 2].

🪟 Conexión SSH desde Windows

Abre el CMD de Windows y conéctate de forma remota escribiendo[cite: 2]:

ssh usuario@ip_servidor → Te pedirá la contraseña del servidor y entrarás directamente a la terminal Linux[cite: 2].

📂 4. Estructura de Directorios y Rutas en Linux

🗂️ El Árbol de Directorios (La Raíz /)

  • /etc: Archivos de configuración del sistema[cite: 2].
  • /home: Ubicación de los usuarios (la tilde ~ representa tu usuario)[cite: 2].
  • /opt: Software de terceros[cite: 2].
  • /usr: Programas propios del servidor[cite: 2].
  • /srv: Datos de servicios (web, ftp)[cite: 2].
  • /var: Datos variables (logs, webs)[cite: 2].

🧭 Tipos de Rutas

  • Absolutas: Empiezan siempre desde la raíz / (ej: cd /home/usuario/facturas)[cite: 2].
  • Relativas: Se mueven desde donde estás ubicado (ej: cd facturas)[cite: 2].
  • Subir niveles: Usando cd .. o encadenados como cd ../..[cite: 2].
pwd → Muestra la ruta exacta de dónde estás situado[cite: 2].

💻 5. Comandos de Archivos, Carpetas y Comodines

👁️ Listar Archivos (ls)

ls Listado normal[cite: 2] ls -l Listado detallado[cite: 2] ls -a Muestra archivos ocultos (con punto)[cite: 2] ls -t Ordena por fecha (recientes primero)[cite: 2]

Comodines de búsqueda (*): A* (empieza por A), *A (acaba por A), *A* (contiene A)[cite: 2].

📝 Crear Archivos y Carpetas

touch archivo.txt Crea archivo en blanco[cite: 2] mkdir carpeta Crea una carpeta[cite: 2] mkdir -p a/b/c Crea estructura anidada de golpe[cite: 2] nano archivo.txt Editor de texto (CTRL+S guardar, CTRL+X salir)[cite: 2]

🗑️ Borrado de Archivos y Carpetas

rm archivo.txt Borra un archivo[cite: 2] rm -i archivo.txt Borra pidiendo confirmación[cite: 2] rmdir carpeta Borra carpeta vacía[cite: 2] rm -rf carpeta Borra carpeta con todo sin previo aviso (¡Peligro!)[cite: 2]
💡 Truco extra de árbol: Si quieres ver de forma gráfica toda la estructura de carpetas tipo esquema, puedes instalar la herramienta ejecutando sudo apt install tree y luego escribir tree[cite: 2].
